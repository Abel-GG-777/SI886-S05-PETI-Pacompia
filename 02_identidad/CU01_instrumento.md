# CU01 Instrumento de diagnostico de cultura organizacional

## Instrucciones

Este instrumento permite diagnosticar la cultura organizacional usando el Competing Values Framework.

Para cada una de las seis dimensiones, distribuya **100 puntos** entre las opciones A, B, C y D segun como percibe actualmente la organizacion. Luego vuelva a distribuir **100 puntos** entre las mismas opciones, segun como considera que deberia ser la organizacion en cinco anos.

La suma de A + B + C + D debe ser exactamente **100 puntos** en cada dimension y en cada momento.

No coloque su nombre. La informacion sera usada solo de forma agregada.
